# PROJECT P.A.N.D.A. Developer Companion updates

Public Android pilot download channel for the internal Developer Companion.

Public bootstrap APKs contain no Game Design Bible catalogue, personal notes, GitHub credentials or signing keys. Authorised users obtain the private Bible through the separately restricted GitHub App connection, then browse it offline.

Use the latest release assets for the APK and its SHA-256 checksum. This channel does not host the REBIRTH game, private source repositories or tracking data.
